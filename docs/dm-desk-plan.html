DM Desk: Instagram automation that runs on your Mac

One Instagram account. Your friend clicks Sign in with Instagram and gets auto-DMs, an inbox, stats, and a hook coach. Everything runs on this Mac and uses only Meta's official API, so the account isn't at risk.

Decision

Fork OpenInstaDM rather than build from scratch

We looked at eight open-source options. OpenInstaDM is the only one that already covers ManyChat-style work on the official API: comment keyword → DM, DM keyword replies, an inbox, a follower chart and tracked links. It's MIT-licensed and built on Next.js. We keep its engine and add three things it lacks: per-post stats, a hook coach, and an Instagram-only login.

Runs on the Mac

  • Web app and worker run as launchd services and restart if they crash
  • Postgres and Redis run through Homebrew services (no Docker)
  • Sleep turned off, auto-restart after a power cut, daily database backup
  • A health check every 5 minutes restarts anything that's stuck

Meta app

  • Instagram API with Instagram Login, so no Facebook Page is needed
  • Scopes: instagram_business_basic, _manage_messages, _manage_comments, _manage_insights
  • Friend added as an Instagram Tester. Standard Access is enough, so no App Review
  • Webhooks: messages, messaging_postbacks, comments

Kept alive automatically

  • The 60-day token refreshes itself daily once fewer than 10 days are left
  • After sign-in, the app subscribes his account to webhooks with one API call
  • Stats are pulled every 3 hours, and reels are re-read for 48 hours while their numbers settle
  • If comment webhooks aren't delivered, the app checks new comments every 60 seconds instead

Hook coach

What it actually measures

Hook

3-second hold = 1 − reels_skip_rate. This is the main signal.

Retention

ig_reels_avg_watch_time divided by video length.

Spread

(Shares + saves) ÷ reach, and follows ÷ reach.

It diagnoses from those numbers. A high skip rate means the first frame, cover or opening line needs work. A low skip rate with short watch time means viewers drop off mid-video. Claude compares his top and bottom posts, then rewrites the weak opener in the style of hooks that already worked for him.

Setup

Who does what

Claude drives almost every step through the shell and the in-app browser. Meta has no API for creating the app, setting up Instagram webhooks or adding testers, so Claude fills those dashboard forms for you while you're logged in.

You · 1 min
Answer 4 questions (below) and log in to developers.facebook.com once in Claude's browser pane.
Claude
Fork and install OpenInstaDM, install Postgres and Redis, write .env, add the stats, hook coach and Instagram-only login, then set up the launchd services, power settings and tunnel.
Claude
In the Meta dashboard: create the app with the Instagram use case, add the scopes, set the redirect, deauthorize and data-deletion URLs (served by our app, along with a privacy page), connect and verify the webhook, tick the fields, add your friend as an Instagram Tester, and switch the app to Live.
You · 1 tap
Approve the sudo prompt for the power settings and the background service.
Friend · 3 taps
Switch to a Professional account if he isn't on one. Accept the tester invite (instagram.com → Settings → Apps and websites → Tester invites). Open the link and tap Sign in with Instagram.
Claude
Test it end to end: comment the keyword from another account, check the DM arrives, check stats are filling in, then send you the link.
Risks

What could go wrong, and the plan for each

Comment webhooks may need Advanced Access. Meta's docs say comments notifications need it, which means App Review. If they don't arrive in Live mode, the app checks his recent posts for new comments every 60 seconds and still sends the private-reply DM. He won't see a difference beyond a delay of up to a minute.
  • 24-hour window. We can only DM someone within 24 hours of their last message, and a comment opens one private reply that has to go within 7 days. So there are no mass broadcasts. Follow-ups go out only after the person taps a button.
  • Rate limits. Meta allows 750 private replies per hour. The queue holds us to about 200 per hour to stay safely under that.
  • The Mac goes offline. Meta retries webhooks for 36 hours, so after a short outage the queue catches up.
  • Token expiry. It refreshes automatically. If it ever lapses, Home shows a single “Reconnect Instagram” button.
  • OpenInstaDM is a young project. We pin the commit we fork from and read the webhook and token code before going live.
